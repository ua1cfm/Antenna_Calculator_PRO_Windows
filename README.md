# Antenna Calculator PRO — Windows

**Версия 0.6.62 · UA1CFM © 2026**  
**Моделирование антенн, диаграммы направленности, электромагнитное поле и измерения VNA**

Antenna Calculator PRO — экспериментальная инженерная программа для Windows, объединяющая расчёт проволочных антенн по моделям **MMANA-GAL (`.maa`)**, анализ импеданса, визуализацию диаграмм направленности и электромагнитного поля, а также работу с **LiteVNA64 / NanoVNA**.

Программа ориентирована на радиолюбителей и специалистов по антенной технике. Проект активно развивается; отдельные численные методы и режимы визуализации требуют дальнейших испытаний.

## Основные возможности

### 1. Моделирование антенн

- Загрузка моделей **MMANA-GAL (`.maa`)** и отображение геометрии проводников.
- Просмотр источников питания, нагрузок и параметров модели.
- Расчёт распределения комплексных токов, входного импеданса **Z = R + jX** и **КСВ** с помощью реализованного в проекте численного решателя MININEC-типа.
- Отображение импеданса на **диаграмме Смита**, анализ частотных характеристик.
- Пакетная обработка моделей и средства диагностики численного расчёта.
- Работа с различными типами антенн: диполями, Яги, вертикалами, рамками, решётками и другими проволочными конструкциями в пределах возможностей используемой модели.

### 2. Диаграммы направленности

- Цветные **2D-диаграммы направленности** с анализом характерных направлений.
- Интерактивная **3D ДН**: вращение, масштабирование и отображение совместно с геометрией антенны.
- Анализ направления максимума излучения и отношения «вперёд/назад» (**F/B**) там, где это применимо.
- В версии **0.6.60** настройка сетки 3D ДН **1°** включает фактический пересчёт дальнего поля с шагом 1°, а не только более плотную сетку полигонов.

### 3. Визуализация электромагнитного поля

- Цветные сечения поля в плоскостях **XY, XZ и YZ**.
- Трёхмерное представление распределения поля, управление обзором и масштабом.
- Отображение электрического **E** и магнитного **H** полей; режимы мгновенной фазы и усреднённых величин, где предусмотрено интерфейсом.
- Радужная палитра, регулировка визуального диапазона и прозрачности.
- CPU-рендеринг и поддерживаемые режимы ускорения на **NVIDIA CUDA**.
- **Векторные стрелки поля** (с версии 0.6.61): направление E/H при выбранной фазе или вектора Пойнтинга в режиме средней мощности; стрелки доступны для 2D и 3D отображения.

**Новое в 0.6.62 — режим 3D «Стекло».** Полупрозрачная визуализация объёма ЭМ-поля: внешние слои просвечиваются, а края и внутренние структуры выделяются цветом и плотностью. Режим предназначен для наблюдения вложенных волновых фронтов. Стрелки векторов в 3D уменьшены вдвое без изменения шага их сетки. Принципы отображения согласованы для CPU и CUDA.

### 4. LiteVNA64 / NanoVNA

В программе предусмотрен отдельный интерфейс для работы с совместимыми VNA через последовательное соединение:

- однократное и непрерывное сканирование частоты;
- отображение **S11 / S21**, КСВ, комплексного импеданса и диаграммы Смита;
- маркеры на графиках и просмотр числовых параметров;
- функции калибровки и экспорта измерительных данных, доступные в соответствующем режиме.

Набор доступных команд и корректность измерений зависят от модели анализатора, версии его прошивки и выполненной калибровки.

## Что изменилось в версии 0.6.62

- Добавлен вариант визуализации ЭМ-поля **«Объём (3D) → Стекло»** с эффектом полупрозрачных поверхностей.
- Для изображения поля используются локальные значения и радужная палитра; параметр **«Плотность»** управляет прозрачностью.
- Размер трёхмерных векторных стрелок уменьшен в два раза.
- Сохранён выбор шага расчёта 3D ДН **1°** (из 0.6.60) и векторные наложения на поле (из 0.6.61).
- Режим «Стекло» реализован для CPU и CUDA. Если установлена устаревшая CUDA DLL, предусмотрено использование CPU-рисования.

## Системные требования

- **Windows x64**.
- **.NET 8** — для сборки и запуска соответствующего WPF-проекта.
- **Visual Studio 2022/2026** с поддержкой .NET Desktop Development — для сборки из исходников.
- **NVIDIA GPU и совместимый CUDA Toolkit** — опционально, для GPU-ускорения. Доступные архитектуры SM зависят от сборки CUDA DLL и установленного драйвера.

Без подходящего CUDA-ускорителя доступны программные режимы, предусмотренные приложением.

## Сборка из исходников

1. Распакуйте архив исходного проекта.
2. Откройте `AntennaCalculator.Windows.sln` в Visual Studio.
3. Выберите конфигурацию **Release | x64** и соберите решение.
4. Для новой функции **«Стекло»** дополнительно пересоберите CUDA Volume DLL с помощью:

   ```bat
   cd Cuda
   BUILD_CUDA_VOLUME_WIN64.bat
   ```

5. При необходимости пересоберите остальные CUDA DLL через `Cuda\BUILD_ALL_CUDA_WIN64.bat`.
6. Запустите собранное WPF-приложение.

При отсутствии совместимой CUDA DLL визуализатор может использовать CPU. Готовые бинарные файлы и наличие CUDA зависят от состава конкретного релиза.

## Важные ограничения

- Расчёт импеданса, ДН и ближнего ЭМ-поля — **разные вычислительные задачи**. Красивая визуализация не является гарантией правильности численного решения.
- Поддержка земли с конечной проводимостью в отдельных режимах может использовать **PEC-приближение**; это не полная модель Sommerfeld/Norton. Результаты для сложных антенн над реальным грунтом рекомендуется проверять по MMANA-GAL, NEC и измерениям.
- Визуализация ближнего ЭМ-поля является инженерной реконструкцией поля и не должна восприниматься как универсальный полномасштабный FEM/FDTD-решатель.
- Проект находится в разработке. Сложные системы связанных проводников, нагрузки и многопортовые конструкции могут требовать дополнительных численных проверок.
